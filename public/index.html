              欢迎使用心灵港湾 🌊

              首次使用只需一步：填入你的 API Key。它只会保存在你自己电脑的 config.json 里（该文件已排除在代码仓库外），不会上传到任何地方。

              Embedding 独立接口（可选，默认与对话模型同一服务）
              MCP 服务器（可选，默认使用仓库自带的演示服务器）

              JSON 数组，每项：stdio 用 {"name":"…","command":"node","args":["server.mjs"]}；HTTP 用 {"name":"…","transport":"http","url":"…"}

              数据备份

              所有数据只存在你自己电脑的 data/ 目录；导出文件为明文 JSON（不含 Key）。

              修改模型后建议重启服务，并运行一次 npm run build:kb 重建知识库向量。
